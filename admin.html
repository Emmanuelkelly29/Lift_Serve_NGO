Setup Checklist

  • - Set flutterwavePublicKey in js/config.js
  • - The admin password is adminPassword in js/config.js
  • - Successful donations are saved in Firestore under donations
  • - Create an unsigned upload preset in Cloudinary → Settings → Upload
